# Autonomous implementation

Complete the selected delivery, including integration, checks, and in-scope fixes,
without asking for approval of each code block. Resolve technical unknowns through
targeted inspection or research and follow existing conventions for routine
implementation choices. Bring consequential unresolved choices back to the user
under the entrypoint's discovery rules. Present the integrated result for review when
the delivery is complete. Default to stopping before another delivery. If the user
explicitly authorized an autonomous milestone, continue through its deliveries
after required review and prerequisite verification, returning at the agreed human
review boundary. Do not record human acceptance or extend scope implicitly.
